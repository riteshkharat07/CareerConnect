# CareerConnect

A multi-page job portal website built using HTML5.

## Pages

- Home
- Jobs
- Job Details
- Apply for a Job
- Contact

## HTML Concepts Used

- Semantic HTML
- Headings and Paragraphs
- Links
- Images
- Lists
- Tables
- Forms
- Input Types
- Radio Buttons
- Checkboxes
- Select and Option
- Fieldset and Legend
- ID and Class
- HTML Entities
- Favicon
- Multi-page Navigation
