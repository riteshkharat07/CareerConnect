# CareerConnect

A responsive, multi-page job portal website built using HTML5, CSS3, and JavaScript.

## Live Demo

https://riteshkharat07.github.io/CareerConnect/

## GitHub Repository

https://github.com/riteshkharat07/CareerConnect

## Pages

- Home
- Jobs
- Job Details
- Apply for a Job
- Contact

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Fetch API
- Async/Await
- Local Storage
- GitHub Pages

## Features

- Responsive design for mobile and desktop
- Job listings and job details
- Job application form with basic validation
- Save application details in browser Local Storage
- Fetch sample user data from a REST API
- Display API data dynamically on the webpage
- Error handling for API requests
- Multi-page navigation
